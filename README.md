# Cono — componi il tuo gelato

App web per comporre un gelato in tempo reale: cono o coppetta, gusti,
decorazioni, glassa ed extra, con anteprima grande e dal vivo.

Il codice sorgente si trova in [`gelato-composer/`](./gelato-composer), dove
trovi anche le istruzioni per avviarla in sviluppo e per la build di
produzione.
